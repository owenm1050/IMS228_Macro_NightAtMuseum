# Night at the Museum — Become the Statue

Red Light / Green Light statue pose game using p5.js and ml5.js.

## How to run
1. Open this folder in VS Code.
2. Right-click `index.html` → **Open with Live Server** (install the Live Server extension if you don't have it),  
   or just open `index.html` directly in a browser (Chrome recommended for camera access).

## Files
- `index.html` — main page
- `style.css` — styles
- `sketch.js` — game logic + pose detection
- `standing-woman.jpg`, `thinker.jpg`, `discus-thrower.jpg` — statue images

Camera permission is required. Pose is checked only on the red-light snapshot.
